# Robert Gregg Personal Portfolio

This repository contains my AI-assisted personal portfolio website created for a course project focused on creativity, ideation, and directing AI tools.

The site highlights my professional experience in collegiate athletics and sports broadcasting, my graduate studies in Applied Business Analytics, and my growing interest in sports analytics and data-informed decision-making.

Throughout the project, I used AI tools to generate initial concepts, compare different design approaches, refine content and layout, and iteratively develop the final portfolio.
